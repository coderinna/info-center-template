
# Don’t be jerk.
Kohtele muita niin kuin haluaisit itseäsi kohdeltavan.

# Älä esitä olevasi kukaan muu.
Ole oma itsesi – älä huijaa tai käytä toisen identiteettiä.

# Kunnioita yksityisyyttä.
Älä jaa toisten henkilökohtaisia tietoja ilman lupaa.

# Ei vihapuhetta tai syrjintää.
Rasismi, homofobia yms. ei kuulu tänne.

# Ei spämmäystä.
Älä täytä keskusteluja turhalla mainoksella tai toistolla.

# Pidä keskustelu aiheessa.
Off-topic on ok satunnaisesti, mutta pysy asiassa.

# Älä jaa laitonta sisältöä.
Piratismi, väkivalta, huumet tai muu lainvastainen toiminta on kielletty.

# Anna rakentavaa palautetta.
Kritiikki on tervetullutta, kunhan se on asiallista.

# Modien sana on laki.
Jos moderaattori käskee jotain, noudata ohjeita.

# Pidä hauskaa ja rakenna positiivista yhteisöä.
Tämä on yhteinen tila – tehdään siitä hyvä kaikille.
