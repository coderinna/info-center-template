
# Don’t be a jerk.
Treat others as you would like to be treated.

# Don’t pretend to be someone else.
Be yourself – don’t cheat or use someone else’s identity.

# Respect privacy.
Don’t share other people’s personal information without permission.

# No hate speech or discrimination.
Racism, homophobia, etc. don’t belong here.

# No spamming.
Don’t fill discussions with unnecessary advertising or repetition.

# Keep the discussion on topic.
Off-topic is okay occasionally, but stay on topic.

# Don’t share illegal content.
Piracy, violence, drugs or other illegal activities are prohibited.

# Give constructive feedback.
Criticism is welcome, as long as it’s relevant.

# The mods’ word is law.
If a moderator asks you to do something, follow the instructions.

# Have fun and build a positive community.
This is a shared space – let's make it good for everyone.
